# 🎓 CampusConnect AI

### AI-Based Career Guidance and Placement Assistance Platform

CampusConnect AI is a web-based platform designed to help students prepare for their professional careers. It brings important career and placement-related features together in one place, including resume analysis, job opportunities, application tracking, and career guidance.

## 🚀 Features

- **User Registration & Login:** Allows students to create accounts and log in.
- **Student Dashboard:** Provides access to the main application features.
- **Student Profile:** Manage personal and profile information.
- **Resume Analyzer:** Upload a PDF resume and receive analysis and feedback.
- **Job Listings:** Explore available job opportunities and skill matching.
- **Application Tracking:** View and manage job applications.
- **Career Roadmap:** Get career preparation guidance.
- **Improved Resume:** Edit resume details with a live preview.
- **PDF Download:** Download the improved resume in PDF format.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/komal101301/CampusConnect-AI.git
```

### 2. Open the Project Folder

```bash
cd CampusConnect-AI
```

### 3. Install Frontend Dependencies

```bash
npm install
```

### 4. Start the Frontend

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

### 5. Start the Backend

Open the `server` folder separately and install its dependencies if it has its own `package.json`. Start the backend using the start command defined in that folder's `package.json`.

The backend API is configured to run at:

```text
http://localhost:5000
```
